# Tayori 開発ドキュメント

更新日: 2026-09-30 / 状態: 初期実装あり（本番検証・Cloudflareリソース作成は未実施）

Tayori は、購読先から届く情報をフォルダに整理して読む個人用アプリです。約50フィードを対象とし、Cloudflare だけで原則0円で運用します。

## 前提の区別

- **確定要件**: ユーザーが明示した条件。
- **設計案**: この文書で具体化した初期値や実装方針。実測後に見直す場合がある。
- **将来対応**: 初期リリースの完了条件に含めない項目。

原則0円は、契約がFreeで既存サービスとの合算利用量が無料枠に収まることが前提です。無料枠や提供条件が将来も不変であること、すべての購読先で常時収集できることは保証しません。
