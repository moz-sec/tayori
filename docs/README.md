# Tayori 開発ドキュメント

更新日: 2026-09-29 / 状態: 初期設計（実装・本番検証は未実施）

Tayoriは、気になる購読先から届く情報を、自分のフォルダで整理して読む個人用アプリです。約50フィードを対象とし、Cloudflareだけで原則0円運用します。
