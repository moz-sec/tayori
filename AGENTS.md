# Agent Instructions

Please provide all answers in Japanese.

## Pull Requests and Issues

- Before creating or updating a PR, read `.github/PULL_REQUEST_TEMPLATE.md` and write the body text following its structure.
- Before creating or updating an issue, select a template from `.github/ISSUE_TEMPLATE/` that matches the content and write the body text following its structure.
- Write the titles and body text of PRs and issues in Japanese.
- In your verification report, describe the actions you actually took and the results. If an action was not performed, clearly state the reason.
- Do not fill in missing information with guesses.

## Commit Attribution

When Codex creates a commit containing changes it authored or co-authored, append
the following trailer to the commit message, separated from the body by a blank
line:

```text
Co-authored-by: Codex <codex@openai.com>
```

Preserve this trailer when preparing a squash commit message.

## CodeRabbit Review

After creating a pull request, review CodeRabbit feedback and make the corresponding changes.
